# Doomscroll Tracker

A computer vision application that tracks screen engagement and detects prolonged scrolling sessions using webcam-based facial and eye tracking.

## Goals

- Experiment with real-time face tracking
- Detect and track eye landmarks
- Estimate whether a user is looking toward their screen
- Measure continuous screen engagement
- Track and visualize scrolling sessions
- Experiment with notifications or intervention mechanisms

## Probable Tech Stack

- Python
- OpenCV
- MediaPipe
- PySide6
- SQLite
- Matplotlib
